# FINANCE

Sistema de controle financeiro pessoal.

Permite registrar entradas e saídas financeiras com histórico persistente.

## Stack

**Frontend**
- HTML
- Sass
- Bootstrap
- TypeScript

**Backend**
- Node.js
- TypeScript

**Banco de dados**
- PostgreSQL
